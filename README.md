# Library-Management-System-using-Python-OOPs

A simple and interactive **Library Management System** developed using **Python, Object-Oriented Programming (OOP), and Streamlit**.

This project demonstrates how OOP concepts can be applied to build a practical real-world application with a user-friendly web interface.

---

## 🚀 Project Overview

The Library Management System allows users to manage books and customers and perform basic library activities such as:

- Viewing library details
- Viewing available books
- Adding new books
- Adding customers
- Issuing books
- Returning books
- Tracking available and issued books
- Managing customer information
- Calculating fines for damaged/late returned books

The application is built using **Python OOP principles** and provides an interactive interface using **Streamlit**.
